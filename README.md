# Git & GitHub Practical Assessment - Personal Portfolio

## Description
This repository contains a simple personal portfolio website built as part of the Git & GitHub Practical Assessment Internship Program. The primary focus of this project is demonstrating standard Git branching, merging, pull requests, recovery operations, and GitHub release workflows.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Desktop

## Features
- **Home (`index.html`):** Navigation header and welcoming message.
- **About (`about.html`):** Background and developer profile summary.
- **Projects (`projects.html`):** Overview of current projects.
- **Contact (`contact.html`):** Interactive contact form with basic JS validation.
